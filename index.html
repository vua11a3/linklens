Trang này giải mã tham số được mã hóa (URL-encoded, Base64) ngay trên trình duyệt. Truy vết HTTP 301/302 thật cần máy chủ: xem tab Backend.

Backend xử lý chuyển hướng

Node.js (Express): endpoint POST /api/resolve với chống SSRF, rate limiting và cache 10 phút.

server.js


    
Cài đặt: npm i express express-rate-limit rồi chạy node server.js (Node 18+).

Kiến trúc hệ thống

  
Thiết kế cho hệ thống Link Expander & Safety Checker chịu tải cao.

  

    
Tech stack đề xuất

    
    
      
  • Frontend: Next.js + Tailwind CSS
    • 
      
  • Backend: Node.js (Express/Fastify) hoặc Python FastAPI
    • 
      
  • Cache & rate limit: Redis (TTL 10 phút)
    • 
      
  • Database: PostgreSQL lưu lịch sử và thống kê
    • 
      
  • Hàng đợi: BullMQ/RabbitMQ cho các lượt quét an toàn chạy nền
    • 
    

  

  

    
Luồng hoạt động

    
    
      
  1. Người dùng dán link, frontend gửi POST /api/resolve kèm token Turnstile.
    2. 
      
  2. API kiểm tra token, rate limit theo IP, validate URL.
    3. 
      
  3. Tra Redis: có cache thì trả ngay.
    4. 
      
  4. Chưa có: giải mã tham số nhanh, rồi theo dõi redirect tối đa 10 bước (đã chặn IP nội bộ).
    5. 
      
  5. Đẩy URL đích vào hàng đợi để quét Google Safe Browsing / VirusTotal.
    6. 
      
  6. Lưu kết quả vào Redis + DB, trả JSON gồm chuỗi chuyển hướng, điểm an toàn, thời gian xử lý.
    7. 
    

  

  

    
Bảo mật bắt buộc

    
    
      
  • Chống SSRF: phân giải DNS rồi chặn IP private/loopback/link-local (kể cả sau mỗi lần redirect), chỉ cho phép http/https, giới hạn timeout và dung lượng.
    • 
      
  • Chống spam: rate limit theo IP, Cloudflare Turnstile/Captcha.
    • 
      
  • Link độc hại: Google Safe Browsing API, VirusTotal API.
    • 
      
  • Khác: chạy fetcher trong container cô lập, không gửi cookie, log có hash IP.
    •
